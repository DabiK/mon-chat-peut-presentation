Politique de confidentialité

Dernière mise à jour : 2025

L'application Mon Chat Peut (ci-après « l'Application ») est éditée par Dabi Keita (ci-après « l'Éditeur », « nous »).

La présente Politique de Confidentialité explique comment nous collectons, utilisons, stockons et protégeons les données personnelles des utilisateurs (« l'Utilisateur », « vous ») conformément au Règlement Général sur la Protection des Données (RGPD) et aux obligations légales applicables.

En utilisant l'Application, vous acceptez les pratiques décrites ci-dessous.

1. Données collectées

Nous collectons uniquement les données nécessaires au fonctionnement de l'Application.

1.1. Données fournies volontairement par l'Utilisateur

  • Nom ou pseudonyme (si renseigné)
  • Adresse e-mail (pour la création de compte et la récupération)
  • Informations sur les chats (nom, âge, poids, stérilisation, race, habitudes, historique alimentaire, quantités)
  • Photos ou images importées (si vous choisissez de les fournir)
  • Préférences et paramètres de l'application

1.2. Données collectées automatiquement

Données techniques

  • Modèle de l'appareil
  • Système d'exploitation
  • Identifiants techniques (Firebase Installation ID, Device ID anonymisé)
  • Adresse IP (anonymisée / stockée de manière temporaire)
  • Version de l'app
  • Logs de fonctionnement

Données d'usage, collectées via Firebase Analytics :

  • Pages consultées
  • Fonctionnalités utilisées
  • Fréquence d'utilisation
  • Statistiques anonymisées de performance

1.3. Données liées aux abonnements

Gérées par RevenueCat :

  • Identifiant de transaction Apple/Google
  • Type d'abonnement (mensuel, annuel, etc.)
  • Statut (actif, expiré, période d'essai)

Important : nous n'avons jamais accès à vos informations bancaires ou de paiement, gérées uniquement par Apple/Google.

1.4. Données liées à la sécurité

  • Événements de connexion
  • Tentatives suspectes
  • Actions pouvant indiquer un abus (anti-fraude)

1.5. Données traitées par l'IA

Si vous utilisez les fonctionnalités d'intelligence artificielle :

  • Texte envoyé à l'IA (ex : description des aliments)
  • Données du profil de votre chat si l'IA doit les prendre en compte

Ces données peuvent être temporairement traitées par les serveurs du fournisseur d'IA, mais ne sont jamais utilisées pour entraîner un modèle ou créer une base externe.

2. Finalités des traitements

Nous utilisons vos données pour :

Fonctionnement essentiel de l'Application

  • Création et gestion de compte
  • Synchronisation cloud
  • Gestion des chats et de leur suivi
  • Analyse nutritionnelle et estimation d'aliments
  • Notifications personnalisées
  • Évaluation des besoins alimentaires

Amélioration de l'Application

  • Statistiques anonymisées
  • Correction de bugs
  • Analyse de performance
  • Ajout de nouvelles fonctionnalités

Sécurité

  • Détection de comportements frauduleux
  • Protection contre les attaques
  • Prévention des abus

Gestion des abonnements

  • Vérification des achats
  • Contrôle du statut premium
  • Application des droits liés à l'abonnement

3. Base légale des traitements (RGPD)

Conformément au RGPD, nos traitements reposent sur :

  • Exécution du contrat : fonctionnement de l'Application, création du compte, synchronisation.
  • Consentement : analytics, IA, notifications.
  • Intérêt légitime : maintien de la sécurité, prévention de la fraude.
  • Obligation légale : facturation Apple/Google, gestion de demandes officielles.

4. Partage des données avec des tiers

Vos données ne sont jamais vendues.

Nous partageons uniquement avec des prestataires nécessaires :

4.1. Firebase (Google)

  • Hébergement des données utilisateurs
  • Analytics & Crashlytics
  • Stockage d'images
  • Authentification

Les données peuvent être transférées vers les États-Unis conformément au Data Privacy Framework.

4.2. RevenueCat

  • Gestion des achats intégrés
  • Vérification du statut d'abonnement
  • Aucun accès aux données bancaires

4.3. Fournisseur d'IA

(Ex : OpenAI, Google Gemini, etc.)

  • Traitement temporaire des données envoyées à l'IA
  • Non utilisé pour l'entraînement de modèles si l'option est désactivée

4.4. Autorités publiques

Si la loi l'exige (fraude, réquisition légale).

5. Durée de conservation des données

Nous conservons :

  • Données du compte : tant que le compte existe
  • Données de chat : tant que vous ne les supprimez pas
  • Logs techniques : 30 à 180 jours
  • Données d'abonnement (RevenueCat) : durée nécessaire au suivi
  • Backups Firebase : entre 7 et 30 jours
  • Données IA : généralement quelques minutes à quelques heures selon le fournisseur

En cas de suppression du compte, la majorité des données est supprimée immédiatement, sauf obligation légale contraire.

6. Sécurité des données

Nous mettons en place :

  • chiffrement des données en transit (HTTPS)
  • chiffrement sur les serveurs Firebase
  • authentification sécurisée
  • contrôle d'accès strict
  • audit de sécurité régulier

Cependant, aucun système n'est sécurisé à 100 %. Nous ne pouvons garantir l'absence totale de faille, attaque ou intrusion.

7. Droits des Utilisateurs (RGPD)

Vous disposez des droits suivants :

  • Droit d'accès
  • Droit de rectification
  • Droit d'effacement (droit à l'oubli)
  • Droit à la limitation du traitement
  • Droit d'opposition
  • Droit à la portabilité
  • Droit de retirer votre consentement
  • Droit d'introduire une réclamation auprès de la CNIL

Vous pouvez exercer vos droits via :

contact@mon-chat-peut.com

Nous répondons sous 30 jours maximum.

8. Suppression du Compte

L'Utilisateur peut supprimer son compte directement dans l'Application.

Cette action entraîne :

  • suppression du profil
  • suppression des données de chats
  • suppression des données stockées dans Firebase

Certaines données nécessaires (ex : données d'achat Apple/Google) peuvent être conservées pour des raisons légales (facturation, sécurité).

9. Transfert hors Union Européenne

Certaines données peuvent être transférées vers les États-Unis via :

  • Firebase (Google) : couvert par le EU-US Data Privacy Framework
  • RevenueCat : conforme GDPR
  • IA : conformité selon fournisseur

Nous ne stockons pas de données en dehors de services conformes au RGPD.

10. Utilisation de Cookies et Trackers

Sur mobile, nous utilisons des SDK équivalents aux cookies :

  • Firebase Analytics
  • Firebase Crashlytics
  • RevenueCat
  • SDK de l'IA (le cas échéant)

Vous pouvez désactiver une partie de ces collectes dans les paramètres de l'Application.

11. Modification de la Politique

Nous pouvons modifier la présente Politique de Confidentialité pour :

  • intégrer de nouvelles lois
  • ajouter de nouvelles fonctionnalités
  • renforcer la sécurité

En cas de changement majeur, une notification vous sera envoyée.

12. Contact

Pour toute question relative aux données personnelles :

contact@mon-chat-peut.com
